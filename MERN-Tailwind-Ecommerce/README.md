# MERN Tailwind E-commerce

A starter e-commerce web application using the MERN stack with Tailwind CSS for the frontend.

## Structure

- `backend/` — Express API, MongoDB models, and sample product data.
- `frontend/` — React app with Tailwind CSS, product catalog, cart, and routes.

## Setup

### Backend

1. Open `MERN-Tailwind-Ecommerce/backend`
2. Run `npm install`
3. Create a `.env` file from `.env.example`
4. Run `npm run dev`

### Frontend

1. Open `MERN-Tailwind-Ecommerce/frontend`
2. Run `npm install`
3. Run `npm start`

## Notes

- The frontend expects the backend at `http://localhost:5000`.
- Use a MongoDB connection string in `.env`.
- This project is a starter template and can be extended with authentication, payments, and admin features.
